# Changelog

All notable changes to **prism** are recorded here, newest first, in the terms that matter to
someone who installs it. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-04

### Added
- `/prism:prism` — panel a question across sole-focus agents, one lens each, in parallel, then get ONE compiled plan back.
- Lens set is open: any lens you name at invocation exists (simple, decoupled, performant, extendable, sustainable are just the starters).
- Every panel returns agreements, conflicts ruled explicitly with their tradeoffs, per-point lens credit, rejected points with reasons, and a line naming what a solo answer would have missed.
- Stateless: no setup, no state files, no artifacts — the conversation is the delivery surface. Safe inside the `mk-cc-all` bundle.
